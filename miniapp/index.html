🛡️ Telegram Security Bot

Protect every group before a dangerous file or link spreads.

A Telegram security layer that scans shared URLs and files with VirusTotal, automatically removes confirmed threats, and gives authorized administrators a daily security report across the groups they manage.

🔍 Automated Scanning

URLs and selected file types are checked automatically when users share them in protected groups.

🗑️ Threat Removal

When a result reaches the configured malicious threshold, the bot deletes the offending Telegram message when it has permission.

📊 Admin Reporting

Authorized users can view daily totals for every group they administer or are assigned to handle.

🔐 Privacy by Design

The Mini App verifies Telegram's signed initData before returning any private dashboard information.

Business Plan

The project can be positioned as a lightweight security service for schools, organizations, teams, and communities that already use Telegram for collaboration.

Problem

Users can accidentally share phishing links, malware, suspicious archives, and weaponized documents in group chats.

Solution

A bot monitors approved groups, uses threat intelligence to classify content, removes confirmed threats, and records security activity.

Target Users

Schools, departments, NGOs, businesses, IT teams, student organizations, and private communities.

Value

Reduce manual moderation, improve incident visibility, and provide a simple security dashboard without requiring users to leave Telegram.

How It Works

A message arrives
The bot receives a Telegram group update and checks the message for URLs or file attachments.
Content is evaluated
Trusted URLs can be skipped, while suspicious candidates are checked with VirusTotal and cached by URL or SHA-256.
Threat is handled
Malicious content can trigger message deletion and a threat alert. Suspicious content can trigger a warning.
Report is recorded
The group receives a daily report containing scans, malicious detections, suspicious items, and deleted messages.
